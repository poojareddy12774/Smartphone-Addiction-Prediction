Machine Learning Model for Prediction of Smartphone Addiction

Project Abstract

The rapid growth in smartphone usage has introduced significant behavioral challenges, particularly among teenagers, where excessive usage can negatively influence mental health, productivity, and social well-being. Accurate prediction of smartphone addiction can assist in early identification of at-risk individuals and support preventive interventions. Previous research has applied machine learning techniques such as Logistic Regression to analyze smartphone usage patterns and classify users as addicted or non-addicted. However, single-model approaches may have limitations in capturing complex behavioral patterns present in large datasets. This study extends an existing machine learning framework for smartphone addiction prediction by introducing a hybrid ensemble learning approach based on a Stacking Classifier. The proposed system integrates multiple base learners, including Random Forest, Gradient Boosting, and Support Vector Machine, while Logistic Regression is used as the meta-learner to combine the predictions of the base models. The model is trained and evaluated using the Teen Smartphone Usage and Addiction Impact Dataset obtained from Kaggle, which contains behavioral and demographic attributes associated with smartphone usage patterns. The experimental evaluation demonstrates that the proposed stacking-based hybrid model significantly improves predictive performance compared to the traditional single-model approach. The developed model achieves an overall classification accuracy of 99%, along with high precision, recall, and F1-score across different addiction categories. The results indicate that ensemble learning techniques are effective in improving the reliability and accuracy of behavioral prediction systems. This research highlights the potential of hybrid machine learning models for enhanced smartphone addiction prediction and provides a scalable framework for future digital well-being monitoring systems.
